# AOS Assignment 1: Start here

This is an **individual assignment worth 50 marks (Stage 1 = 20; Stage 2 = 30)**. Use Python 3.10 or newer. No extra Python libraries are required.

Read `AOS_A1_Student_Brief.docx` first. The brief explains the research work, the Word discussions, the exact file names, examples, marks and the two dates.

## Stage 1: Research and experiment plan
**Submit by Monday, 9 November 2026, 11:59 PM PKT.**

1. Obtain your assigned experiment ID.
2. Create the folder:

   `python starter/student_cli.py init --token YOUR_ID --work my_a1`

3. Complete these five files:
   - `my_a1/research/literature.csv`
   - `my_a1/research/research_question.json`
   - `my_a1/research/hypotheses.json`
   - `my_a1/experiments/experiment_plan.json`
   - `my_a1/research/stage1_research_note.docx` (one-page research discussion)
4. Record the completed work:

   `python starter/student_cli.py freeze --token YOUR_ID --work my_a1`

5. Before uploading, check the Stage 1 files with `python starter/student_cli.py check-stage1 --token YOUR_ID --work my_a1`.
6. Upload **all five files above plus `my_a1/design_snapshot.json`**. There are SIX Stage 1 files. Use the first LMS slot. Do not change these files after submission.

## Stage 2: Run experiments and explain what you found
**Submit by Sunday, 15 November 2026, 11:59 PM PKT.**

1. Generate baseline and custom-run evidence:

   `python starter/student_cli.py run --token YOUR_ID --work my_a1`

2. Compare your actual findings directly with the ORIGINAL H01 and H02 and their planned Kxx comparisons from Stage 1. Complete these Stage 2 files:
   - `my_a1/analysis/findings.json`
   - `my_a1/analysis/contradictions.json`
   - `my_a1/analysis/limitations.json`
   - `my_a1/recommendation.json`
   - `my_a1/analysis/stage2_discussion_note.docx` (one-page results discussion)
3. The `evidence/` folder is generated by the Python program. Do not edit its files.
4. Validate the complete folder:

   `python starter/student_cli.py check --token YOUR_ID --work my_a1`

5. After correcting any errors, create the final ZIP:

   `python starter/student_cli.py pack --token YOUR_ID --work my_a1 --zip AOS_A1_YOUR_ID.zip`

6. Submit **one ZIP** to the second LMS slot. It includes the unchanged Stage 1 files and all Stage 2 files.

A successful `check` checks structure, Word-file completeness and numerical results. It does not guarantee the explanations will receive full marks. The instructor checks both plain-English Word discussions and the linked JSON/CSV evidence.

**Important:** Stage 1 is marked only from the six files uploaded by 9 November. Stage 2 is marked by comparing the new evidence and explanations against those unchanged Stage 1 files. Editing the original predictions later will invalidate the comparison.
